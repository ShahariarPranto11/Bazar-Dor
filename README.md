# 🛒 বাজার দর (BazarDor)

**BazarDor** is a Bengali-language web application that helps users explore daily essential products and check their prices in one place. It provides a simple and responsive interface for browsing products by category and viewing price changes.

## 🚀 Technologies Used

- **Next.js** — React framework for building the web application
- **React** — Building interactive user interfaces
- **TypeScript** — Type-safe JavaScript development
- **Tailwind CSS** — Responsive styling and layout
- **daisyUI** — Reusable UI components
- **REST API** — Fetching product, category, and price information
- **BetterAuth** — User authentication with email/password and social login

## ✨ Key Features

1. **Product Browsing:** Explore essential products and their current prices.
2. **Category Filtering:** Browse products by categories such as rice, lentils, oil, vegetables, fish, and meat.
3. **Price Ticker:** View product prices and price-change indicators in a scrolling ticker.
4. **Responsive Design:** Use the application on mobile, tablet, and desktop devices.
5. **User Authentication:** Register, sign in, and use supported social login options.

## ⚙️ Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL: https://github.com/ShahariarPranto11/Bazar-Dor.git
   ```

2. Navigate to the project directory:

   ```bash
   cd bazar-dor
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure the required environment variables in a `.env.local` file.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open [http://localhost:3000](http://localhost:3000) in your browser.
